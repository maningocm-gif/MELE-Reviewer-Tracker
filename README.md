# MELE Reviewer Tracker

An independent Mechanical Engineering study platform designed for MELE review. The application is a single self-contained `index.html` intended for GitHub Pages and browser-local use.

## v1.3.0 — Organization, Mock Exams & Study Planning

### Highlights
- Elegant academic cream/navy/beige UI
- Subject symbols for the dashboard
- Formula Bank grouped by subject with working subject views
- Terms & Definitions grouped by subject and topic
- Study Notes grouped by subject and topic
- Engineering Situations organized by subject/topic
- Weak Topics organized in aligned subject sections
- Cleaner Study Item modal
- Custom multiple-choice Mock Exam
- Custom question count and time limit
- Mock Exam results recorded into normal progress/mistake tracking
- My Materials link/text ingestion and local deterministic distribution into reviewer categories
- Dark theme with additional background designs and font choices
- Ace can search built-in reviewer content and saved progress/mistakes
- Ace chat history, new chat, and saved chats
- Daily motivational quote
- Daily study alarm with browser notification support when available
- Exam date countdown and exam-day good-luck message
- Study streak tracking

## Important limitations

Ace is a local rule-based study assistant, not a hosted large language model. A public URL may block browser-side reading because of CORS; pasted text works locally. PDF files can be stored/referenced, but arbitrary PDF semantic extraction is not claimed without a dedicated parser/OCR system.

Study alarms depend on the page being open or browser notification support; a plain static HTML page cannot guarantee background reminders after the browser is fully closed.

This is an independent study tool and is not affiliated with or endorsed by PRC.

## GitHub Pages

1. Upload `index.html` to the repository root.
2. Enable GitHub Pages from the repository settings.
3. Open the published Pages URL.

The `versions/` folder is an archive and is not required for the live page.
