# MELE Reviewer

A web-based reviewer designed to help Mechanical Engineering students prepare for the Mechanical Engineer Licensure Examination (MELE).

## Features

- Review topics and questions
- Practice quizzes
- Track study progress
- Simple and clean user interface
- Works directly in the browser

## Built With

- HTML
- CSS
- JavaScript
