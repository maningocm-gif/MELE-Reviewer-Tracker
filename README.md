# MELE Reviewer v1.3.4

Elegant, responsive, single-file Mechanical Engineering licensure study platform.

## Highlights
- Dashboard retains the v1.3.2-chat academic visual direction.
- Mock Exam supports fresh randomized attempts, custom length/time, answer review, and Take Again.
- My Materials can analyze readable TXT/CSV/JSON/MD and attempt text extraction from text-based PDFs.
- Paste real problem sets directly into Practice Arena.
- Source problem sets are retained as inspiration/source records.
- Deleted materials move to a 30-day Trash before permanent deletion.
- Ace chat history can be saved, reopened, renamed by first prompt, and started fresh.
- Ace reads built-in reviewer content plus locally stored progress, mistakes, and extracted materials.

## GitHub Pages
Upload `index.html` to the repository root. No backend is required.

## Limitation
A single browser HTML file cannot reliably OCR scanned images or every PDF, and some URLs block browser fetching through CORS. The app reports those cases instead of pretending it read content it could not access.

Independent study tool; not affiliated with or endorsed by PRC.
